# تطبيق متبرع إب - نسخة تجريبية

تطبيق Flutter مبسط لتجربة فكرة البحث عن متبرعي الدم داخل محافظة إب.

الوظائف:
- البحث حسب فصيلة الدم.
- البحث حسب المديرية.
- بيانات متبرعين تجريبية.
- تسجيل متبرع.
- إنشاء طلب دم عاجل.
- واجهة عربية RTL مناسبة للتطوير لاحقًا.

مهم: جميع الأسماء والأرقام في هذه النسخة تجريبية وليست بيانات أشخاص حقيقيين.

التشغيل:
flutter pub get
flutter run

إنشاء APK:
flutter build apk --release

ثم يوجد الملف عادة في:
build/app/outputs/flutter-apk/app-release.apk
